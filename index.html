📱 Usar como app nativa en tu móvil

Una vez publicada en GitHub Pages, puedes añadir este Hub a la pantalla de inicio de tu teléfono para abrirlo a pantalla completa en un toque:

🤖 En Android (Google Chrome)

  1. Abre la URL de tu GitHub Pages en Chrome.
  2. Pulsa el botón de menú ⋮ (arriba a la derecha).
  3. Selecciona «Añadir a pantalla de inicio» (o «Instalar aplicación»).
  4. Confirma el nombre UNED Arcade y pulsa Añadir.

🍎 En iPhone / iPad (Safari)

  1. Abre la URL de tu GitHub Pages en Safari.
  2. Pulsa el icono de Compartir (cuadrado con flecha hacia arriba) en la barra inferior.
  3. Desliza hacia abajo y toca «Añadir a pantalla de inicio».
  4. Pulsa Añadir arriba a la derecha. ¡Listo!

📁 Estructura recomendada para GitHub Pages

Organiza tu repositorio con esta estructura de carpetas para que todos los enlaces del menú funcionen automáticamente: 

/ (raíz del repositorio)
├── index.html
├── logica/
│   ├── tableau_quest.html
│   ├── predicados.html
│   ├── examen.html
│   ├── setquest_conjuntos.html
│   ├── nexus_relacional.html
│   └── biyeccion_blitz.html
├── fp/
└── ia/

🚀 Activar GitHub Pages en 3 pasos

  1. Crea un repositorio público en GitHub y sube index.html y la carpeta logica/.
  2. Ve a Settings → Pages en tu repositorio.
  3. En Branch elige main y carpeta /(root), pulsa Save y en 1 minuto tendrás tu URL activa.
